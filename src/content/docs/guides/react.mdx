## Installation

Install the starlight-tailwind-variants package:

```bash
npm install starlight-tailwind-variants
```

Install React and required dependencies:

```bash
npm install react react-dom @types/react @types/react-dom
```

## Usage

Here's how to create a simple form card using React components:

### Code

```tsx
import { Badge } from '@/components/ui/Badge'
import { Input } from '@/components/ui/Input'
import { Button } from '@/components/ui/Button'
import { Label } from '@/components/ui/Label'

export function ContactForm() {
  return (
    <div className="max-w-md mx-auto bg-white rounded-lg shadow-md p-6 space-y-4">
      <div className="flex items-center justify-between">
        <h2 className="text-xl font-semibold">Contact Form</h2>
        <Badge variant="secondary">New</Badge>
      </div>
      
      <div className="space-y-2">
        <Label htmlFor="name">Full Name</Label>
        <Input id="name" placeholder="Enter your name..." />
      </div>
      
      <div className="space-y-2">
        <Label htmlFor="email">Email</Label>
        <Input id="email" type="email" placeholder="Enter your email..." />
      </div>
      
      <div className="flex gap-2">
        <Button color="primary">Submit</Button>
        <Button>Cancel</Button>
      </div>
    </div>
  )
}
```
